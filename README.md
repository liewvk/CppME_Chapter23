# CppME Chapter 23

This repository contains a collection of C++ example programs associated with Chapter 23 of the "C++ Programming Made Easy" series. The focus of this chapter is on common Standard Library containers and algorithms, especially `std::vector` and `std::map`, along with basic iteration and sorting patterns.

## Repository overview

The solution includes a root Visual Studio project and a set of standalone example projects, each demonstrating a small concept in a clean, isolated example.

### Root project files
- `CppME_Chapter23.cpp` – the default C++ console project entry point generated by Visual Studio.
- `CppME_Chapter23.vcxproj` and `CppME_Chapter23.vcxproj.filters` – project configuration files for the main project.
- `CppME_Chapter23.slnx` – solution file listing all example projects in the solution.

## Example projects

### `CppME_Chapter23_Example23.8`
Demonstrates basic vector behavior:
- creating a `std::vector<int>`
- adding values with `push_back()`
- checking the size of the vector
- removing the last item with `pop_back()`

### `CppME_Chapter23_Example23.9`
Shows how to iterate through a vector using a classic indexed loop:
- add several integers to `std::vector<int>`
- print each value using `numbers[i]`
- understand vector indexing and traversal

### `CppME_Chapter23_Example23.15`
Introduces `std::map` with integer keys and string values:
- map of student IDs to names
- direct lookup using `students[101]`
- output of selected values

### `CppME_Chapter23_Example23.17`
Extends the map concept by iterating over all key-value pairs:
- range-based loop over `std::map<int, string>`
- accessing `item.first` and `item.second`
- printing every student record

### `CppME_Chapter23_Example23.22`
Demonstrates sorting a vector using `std::sort`:
- create an unsorted vector
- sort values in ascending order
- print the ordered sequence

### `CppME_Chapter23_Example23.27`
Reads five marks from user input and calculates the average:
- use `std::vector<int>` to store values
- sum values in a loop
- display the mean using `sum / 5.0`

### `CppME_Chapter23_Example23.28`
Shows a map storing names and scores:
- `std::map<std::string, int>`
- assign values by name
- loop through each entry and print a report

## Technologies and libraries used

This project uses only the C++ Standard Library, including:
- `iostream`
- `vector`
- `map`
- `algorithm`
- `string`

## Build and run

This repository is configured as a Visual Studio solution for Windows-based C++ development.

### Requirements
- Microsoft Visual Studio 2022 or a compatible C++ IDE
- C++ desktop development workload
- Windows environment (project files are `.vcxproj` based)

### Typical workflow
1. Open `CppME_Chapter23.slnx` in Visual Studio.
2. Build the solution.
3. Run the selected example project.

## Learning goals

These examples illustrate several core C++ programming concepts:
- container selection (`vector` vs `map`)
- insertion and removal operations
- indexed and range-based iteration
- key-value associations
- sorting data
- reading and processing user input

## Notes

This is a small instructional codebase intended for learning and experimentation. Each project focuses on a specific concept and is intentionally simple so beginners can follow the logic and understand the fundamentals.
